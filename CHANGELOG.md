# Changelog

## v0.1.0 (2026-10-12)

The initial framework release.

- **Definition:** emotional connection as eight observable behaviors.
- **Test cases:** 16, two per dimension, each with a rubric and maintainer-written illustrative weak and strong replies.
- **Supporting material:** JSON schema, a 15-item failure-mode taxonomy, and an LLM-as-judge prompt template.
- **Tools:** `tools/ecb.py`, with validate, list, messages, judge and score commands.
- **Docs:** methodology, related work, and scope and safety.
- **Results:** none published.
