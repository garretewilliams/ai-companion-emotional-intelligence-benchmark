# Results

**No results have been published yet.**

This directory will hold evaluation runs submitted by the maintainers or the community. Each run must include:
- the benchmark version (git tag)
- the system and version, model, and settings
- every raw reply
- per-test scores in JSONL, as described in the [methodology](../docs/methodology.md)
- who scored the replies (human raters and/or judge model and version)
- any conflicts of interest

Results without raw replies will not be accepted. ChatBrat, which maintains this benchmark, will label any results about its own product as such.
